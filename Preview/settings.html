what changed

Live palette banner at the top

Shows the current track as a mini chip. Pulled from the live SPTPlayer state, same source as the Now Playing bar. The green ON dot confirms the hook is firing. Feels alive, not static.

Glass panels per section, not a flat table

Each section is its own tinted sheet with a short amber stripe before the header. Reads as architecture rather than iOS Settings. Still no boxed card grid: the content inside flows as rows.

Custom toggle pill with amber glow

When ON it is a warm gradient with a subtle outer glow. OFF is a flat charcoal pill. Not the default iOS blue switch. The glow brightness tracks the current album palette, so toggles shift color between tracks.

Inline tiny sub-labels

Only where a toggle name alone is ambiguous (Fisher Yates shuffle → true uniform, not weighted). No grey instructions under every row.

Credentials get real input chips

Monospace field with a paste glyph on the right. Secrets show as dots. Tap the glyph, it reads the clipboard. Session key stays in sync with the Last.fm callback.

Prominent CTA for sign-in

The one action that leaves the panel gets a proper pill button in brand orange, not a plain row. It stands out, so first-time setup is one tap once the key is pasted.

Footer: Discord link, version mark

Lives in its own quiet strip at the bottom. Clickable, not decoration.
